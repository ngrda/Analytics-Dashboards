# Analytics Dashboards Repo by Nuria García Ruiz de Alarcón
Personal repository featuring data-driven dashboards and analytics web apps — interactive tools built with Python (Flask, pandas) and front-end frameworks like Tailwind CSS and Chart.js.
A curated collection of dashboard builds and demos.

## 🛠️ Projects
* **Expense-Revenue-Tracker-Dashboard/** ⭐ — Personal finance dashboard that reads income and expenses straight from Excel files and turns them into an interactive report: KPIs, budget-vs-actual, category breakdown, monthly trend, and a savings tracker. Built with Flask, pandas, Tailwind CSS, and Chart.js. — [Documentation](./Expense-Revenue-Tracker-Dashboard) · [Live Demo](https://expense-revenue-tracker-dashboard.onrender.com)
* **Gym-Tracker-Dashboard/** 🏋️ — Fitness tracking dashboard that reads workout data straight from Excel files and turns them into an interactive report: progress tracking, personal records, and training trends over time. Built with Flask, pandas, Tailwind CSS, and Chart.js. — [Documentation](./Gym-Tracker-Dashboard) · [Live Demo](https://gym-progress-dashboard.onrender.com)
* **Events-Insight-and-Sales-Dashboard/** 🎬 — Weekly sales dashboard for an event/concession business that reads data straight from CSV files and turns it into an interactive report: KPIs, category breakdown, top products, and weekly trends. Built with Flask, pandas, Tailwind CSS, and Chart.js. — [Documentation](./Events-Insight-and-Sales-Dashboard) · [Live Demo](https://moonlight-movies-analysis.onrender.com)

---
## 🚀 Usage
Each project folder contains its own README with setup and usage instructions. Most dashboards in this repo are backed by a small Flask server — just open the Live Demo link and you will be able to explore the data, no installation required.
